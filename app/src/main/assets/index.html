APK Studio — Guide

إنشاء المفتاح طريقة الاستخدام حل المشاكل

أولاً: كيف تنشئ مفتاح GitHub (Token)

المفتاح هو كلمة سر خاصة تسمح للأداة برفع ملفاتك إلى مستودعك على GitHub. تنشئه مرة واحدة فقط، وتلصقه في الأداة بنفسك.
0
تجهيز المستودع (إن لم يكن موجوداً) افتح هذا الرابط في المتصفح: github.com/new في خانة اسم المستودع اكتب: myapp اختر: Public ثم اضغط: Create repository المستودع يجب أن يحتوي ملفاً واحداً على الأقل. إن كان فارغاً أنشئ فيه أي ملف، مثل README.
1
سجّل الدخول إلى GitHub افتح الموقع وسجّل دخولك بحسابك. github.com
2
افتح صفحة إنشاء المفتاح اضغط الزر التالي لفتحها في تبويب جديد:
Open token page
وإن لم يفتح، افتح هذا الرابط: github.com/settings/tokens ثم اضغط: Generate new token واختر: Generate new token (classic) لا تختر الخيار الأول (Fine-grained) لأنه لا يعمل مع الأداة. قد يطلب منك GitHub كلمة المرور، فأدخلها.
3
اكتب اسماً للمفتاح في خانة الاسم اكتب: apk-studio الخانة اسمها: Note
4
حدّد مدة الصلاحية في القائمة المنسدلة اختر: 90 days اسم القائمة: Expiration بعد انتهاء المدة تنشئ مفتاحاً جديداً بنفس الخطوات.
5
فعّل صلاحيتين فقط ضع علامة صح على المربعين التاليين، ولا تفعّل غيرهما: repo workflow عند تفعيل repo تتفعل المربعات الصغيرة تحته تلقائياً، وهذا طبيعي. أما workflow فمربع مستقل يقع بعده بقليل، فتأكد منه.
6
أنشئ المفتاح انزل إلى آخر الصفحة واضغط الزر الأخضر: Generate token
7
انسخ المفتاح فوراً سيظهر نص أخضر طويل يبدأ بهذه الأحرف: ghp_ اضغط أيقونة النسخ بجانبه. لا تغلق الصفحة قبل النسخ، لأن GitHub لا يعرضه مرة ثانية.
8
الصقه في الأداة ارجع إلى الأداة وافتح الصندوق رقم 01. الصق المفتاح في الخانة: Access token ثم اضغط: Save & test connection انتظر ثواني حتى تظهر رسالة خضراء تبدأ بـ: Connected to وبعدها يظهر اسمك أعلى الصفحة وتصبح الأداة جاهزة.
تنبيه أمني: لا تكتب المفتاح داخل ملفات تطبيقك ولا ترسله لأحد ولا تنشره. إن تسرّب، احذفه فوراً من هذه الصفحة وأنشئ غيره: github.com/settings/tokens وإن وُجد مفتاح داخل الملفات، سيرفض GitHub رفعها، وتوقف الأداة البناء أيضاً.

ثانياً: طريقة استخدام الأداة

1
الاتصال أكمل الصندوق 01 كما شرحنا أعلاه. اسم المستخدم والمستودع يجب أن يطابقا ما في GitHub.
2
معلومات التطبيق (02) اكتب اسم التطبيق الذي سيظهر تحت أيقونته. أما معرّف الحزمة فهو اسم فني فريد، مثال: com.myapps.game1 شروطه: حروف إنجليزية صغيرة وأرقام، بلا مسافات، وفيه نقطة واحدة على الأقل. لكل تطبيق جديد اضغط "New app ID" ليولّد لك معرّفاً جديداً، وإلا سيُحدَّث التطبيق القديم.
3
الهوية والألوان (03) ارفع أيقونة مربعة، أو اتركها فتُصنع أيقونة تلقائية بالحرف الأول. اختر لون شريط الحالة وشريط التنقل وخلفية التحميل.
4
السلوك (04) اختر اتجاه الشاشة، ثم فعّل ما تحتاجه: ملء الشاشة، الوضع الغامر للألعاب، إبقاء الشاشة مضاءة، الإنترنت، التشغيل التلقائي للصوت، فتح الروابط في المتصفح، منع التكبير، منع تحديد النص، والضغط مرتين على رجوع للخروج.
5
الصلاحيات (05) فعّل الكاميرا أو المايكروفون أو الموقع إن احتاجها تطبيقك. ألعاب النطق تحتاج المايكروفون. سيطلب أندرويد الموافقة من المستخدم عند أول فتح.
6
ملفات تطبيقك (06) لديك طريقتان: اضغط على مربع الرفع واختر ملفاتك (أو ملف ZIP فيه موقعك كاملاً)، أو الصق الكود في التبويبات الثلاثة. هذه الخانات لكود تطبيقك أنت فقط، وليست لكود الأداة. وإن امتلأت بالخطأ اضغط: Reset form
7
المعاينة (07) تعرض شكل تطبيقك مباشرة. تأكد أنه يعمل قبل البناء.
8
ابنِ التطبيق اضغط الزر الثابت في الأسفل: Build APK تظهر المراحل في الصندوق 08. المرحلة الخامسة تأخذ من 2 إلى 5 دقائق، فلا تغلق الصفحة ولا تخرج من المتصفح حتى تنتهي.
9
نزّل التطبيق وثبّته عند النجاح يظهر زر برتقالي: Download APK اضغط عليه، ثم افتح الملف من التنزيلات ووافق على التثبيت من مصدر غير معروف إن طلب الهاتف. يمكنك أيضاً مسح رمز QR لتنزيله على هاتف آخر.
10
البناءات السابقة (09) تحفظ الأداة آخر 10 تطبيقات بنيتها لتنزلها لاحقاً. وكل بناء جديد يستبدل ملفات المشروع في المستودع، فلتطبيقات منفصلة استخدم لكل تطبيق Package ID مستقلاً.

Part 1: How to create a GitHub token

The token is a private password that lets this tool upload your files to your GitHub repository. You create it once and paste it into the tool yourself.
0
Prepare the repository (if you do not have one) Open: github.com/new Repository name: myapp Choose: Public Then press: Create repository The repository must contain at least one file. If it is empty, add any file such as README.
1
Sign in to GitHub Open the website and sign in. github.com
2
Open the token page Press this button to open it in a new tab:
Open token page
If it does not open, go to: github.com/settings/tokens Press: Generate new token Then choose: Generate new token (classic) Do not choose the first option (Fine-grained); it does not work with this tool. GitHub may ask for your password.
3
Name the token In the field called: Note type: apk-studio
4
Set the expiration In the dropdown called: Expiration choose: 90 days When it expires, create a new one with the same steps.
5
Enable exactly two scopes Tick these two boxes and nothing else: repo workflow Ticking repo automatically ticks the small boxes under it; that is normal. workflow is a separate box a little lower, so double-check it.
6
Generate the token Scroll to the bottom and press the green button: Generate token
7
Copy it immediately A long green text appears, starting with: ghp_ Tap the copy icon next to it. Do not close the page before copying; GitHub never shows it again.
8
Paste it into the tool Come back to the tool and open box 01. Paste the token into: Access token Then press: Save & test connection After a few seconds you should see a green message starting with: Connected to Your username then appears at the top and the tool is ready.
Security: never write the token inside your app files, never send it to anyone and never post it. If it leaks, delete it right away on this page and create a new one: github.com/settings/tokens If a token is found inside the files, GitHub rejects the upload and this tool stops the build too.

Part 2: How to use the tool

1
Connection Complete box 01 as described above. The username and repository must match GitHub exactly.
2
App info (02) Type the app name shown under its icon. The package ID is a unique technical name, e.g.: com.myapps.game1 Rules: lowercase letters and digits, no spaces, at least one dot. For every new app press "New app ID" to generate a new one, otherwise the old app is updated instead.
3
Branding (03) Upload a square icon, or leave it empty and an icon is generated from the first letter. Pick the status bar, navigation bar and loading background colors.
4
Behavior (04) Choose the screen orientation, then switch on what you need: fullscreen, immersive mode for games, keep screen awake, internet, autoplay media, open links in browser, disable zoom, disable text selection and double back to exit.
5
Permissions (05) Enable camera, microphone or location if your app needs them. Speech games need the microphone. Android asks the user to allow each one on first launch.
6
Your app files (06) Two ways: tap the upload area and choose your files (or one ZIP with the whole site), or paste code into the three tabs. These boxes are for YOUR app code only, not the tool's code. If they are filled by mistake, press: Reset form
7
Preview (07) Shows your app live. Check that it works before building.
8
Build the app Press the fixed button at the bottom: Build APK Progress appears in box 08. Step five takes 2 to 5 minutes, so do not close the page or leave the browser until it finishes.
9
Download and install On success an orange button appears: Download APK Tap it, open the file from Downloads and allow installing from unknown sources if the phone asks. You can also scan the QR code to download on another phone.
10
Previous builds (09) The tool keeps your last 10 builds for later download. Every new build replaces the project files in the repository, so for separate apps use a separate Package ID for each.

Part 3: Troubleshooting

!
New app overwrites the old one You are using the same Package ID. Press New app ID before each new app.
!
Token invalid or expired Create a new token with the steps above and make sure you pasted it whole, without spaces.
!
Repository not found Check the username and repository name, and that this scope is enabled: repo
!
Repository is empty Add any single file (such as README) on the GitHub website, then try again.
!
Token found inside files Your files contain text that looks like a token. Remove it from the code, press Reset form and paste only your real app code.
!
Build failed Open the build log link shown under the message and send me the error screenshot. Also make sure this scope is enabled on your token: workflow
!
Build did not start Open the Actions tab of your repository on GitHub and make sure it is enabled.
